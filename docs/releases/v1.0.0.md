## Summary

- Run batch commands with the `relay-jobs` executable from the `relay-jobs-cli` repository, with Linux and macOS binaries for amd64 and arm64.
- Define project jobs in `relay-jobs.toml` and user settings in `~/.config/relay-jobs/relay-jobs.toml`.
- Keep coordinator state, worker workspaces, installed services, and native execution jobs under the `relay-jobs` names, with separate worker state and cache directories.
- Install the matching `relay-jobs` agent skill for command, configuration, recovery, and service guidance.

The renamed defaults use separate paths from earlier versions. Existing configuration and state are not discovered or migrated automatically.
