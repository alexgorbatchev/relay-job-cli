## Summary

- `worker list` probes configured workers concurrently and returns healthy workers alongside individual offline-worker errors, preserving configuration order.
- Worker availability has a one-second default budget covering connection wait, SSH setup and health response. Configure it with `--worker-timeout` or `[coordinator] worker_timeout` in user TOML; explicit service installation overrides persist across restarts.
- The listing client allows time to receive timeout results, including when a configured probe budget exceeds its previous two-second request deadline.
