## Summary

- Run ordinary commands on persistent Linux and macOS workers, with incremental source synchronization and reusable dependency directories.
- Configure paths, workers, concurrency, retention and named project jobs through strict TOML files, with explicit CLI overrides.
- Recover interrupted connections by durable job ID without replaying accepted commands; stream original stdout/stderr and preserve command exit status.
- Clean up old collected logs and idle workspaces while preserving active work, receipts, execution markers and replay protection.

Local fallback is opt-in and available only before remote submission. Jobs run with the worker account's permissions and require its toolchain; execution is not sandboxed.
